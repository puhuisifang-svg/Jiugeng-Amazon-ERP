# 成员交付物目录

每个项目成员在自己的目录提交正式成果：

- `pjm/`：项目章程、Sprint、状态、风险、验收汇总
- `pm/`：调研、流程、PRD、Backlog、指标口径
- `ui/`：信息架构、原型、视觉与交互规范
- `frontend/`：前端设计说明、接口联调、构建与自测报告
- `backend/`：架构、数据模型、API、集成和自测报告
- `qa/`：测试计划、用例、报告和缺陷总结
- `ops/`：环境、CI/CD、部署、监控、备份和演练记录

成果必须使用 [交付物模板](../templates/DELIVERABLE_TEMPLATE.md)，并登记到 [交付物总账](../docs/DELIVERABLE_REGISTER.md)。

不得在任何交付物中粘贴真实 Token、Key、密码、私钥或生产敏感数据。
