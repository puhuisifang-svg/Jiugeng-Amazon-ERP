# S0-BE-01 CollectorAdapter 合规 Spike

## 目标

验证批准的 Amazon 美国站公开店铺数据源在合规性、覆盖率、完整性、稳定性、成本和人工降级方面是否适合 MVP。此目录只提供框架和证据结构，不包含绕过登录、验证码、访问控制或反爬机制的能力。

## 安全边界

1. 仅使用经 PJM/Ops 批准的数据源和公开访问方式，第三方合规 API 优先。
2. 遇到登录、验证码、访问拒绝、限流或 robots/服务条款限制，立即记录 `BLOCKED_POLICY` 或 `RATE_LIMITED`，不得规避。
3. 不保存 Cookie、会话、个人信息或真实密钥；凭据仅使用 SecretRef，在运行时注入。
4. 原始响应只保留完成业务验证所需字段，并按批准的保留期删除。
5. 不完整、失败或校验未通过的快照永远不得覆盖有效基线。

## 结构

- `schemas/`：快照清单、完整性结果、基线决策、差异事件、运行证据的 JSON Schema。
- `templates/`：数据源审批、每日观察与 7 天结论模板。
- `observations/`：收到 3 店链接后，每店每天一份观察记录。
- `evidence/`：原始证据对象仅存受控对象存储引用；仓库不提交响应正文。
- 后端工程 `watch.collector` 包：Adapter 契约、完整性判定、基线保护与差异去重 Spike 实现。
