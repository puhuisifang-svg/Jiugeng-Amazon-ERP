# ERP-003 选品监控来源与安全基线批次

## 目标

在 ERP-002 候选管理闭环上补齐模拟监控来源链路，使选品人员能够查看监控店铺、执行合成快照、识别新增 ASIN，并保证失败或不完整快照不会覆盖最后一个有效基线。

本批次继续只使用 `SYNTHETIC` 内存数据，不访问 Amazon，也不作为真实采集器或生产数据源验收。

## 范围

1. 提供模拟监控店铺列表、当前有效基线和最近运行结果。
2. 支持执行三类合成运行：完整快照、不完整快照、失败快照。
3. 首次完整快照仅建立基线；后续完整快照按 ASIN 集合差异生成待复核事件。
4. 失败、空结果、分页不完整或完整性校验失败的快照不得替换有效基线。
5. 同一店铺同一 ASIN 只生成一个首发事件。
6. 事件确认后生成或复用候选，并保留店铺、运行和事件来源关系。
7. 将“监控店铺”路由从占位页替换为可操作页面。

## 不在范围

- 真实 Amazon 页面采集、绕过登录/验证码/反爬或第三方数据 API 接入。
- 定时任务、消息通知、生产数据库持久化和多站点。
- 销量估算、AI 自动决策和评论语义分析。

## 实施顺序

1. 扩展 mock 领域数据：店铺、快照运行、基线决策、事件来源字段。
2. 提供监控店铺查询和合成运行 API，并复用快照完整性与基线保护规则。
3. 补齐后端基线保护、差异去重、权限和来源追溯测试。
4. 新增监控店铺页面、API 类型与交互。
5. 补齐前端页面/API 测试，运行 lint、typecheck、测试和生产构建。

## 验收标准

- 首次完整运行返回 `PROMOTED`，事件数为 0，基线运行 ID 被记录。
- 第二次完整运行只为新增 ASIN 生成事件，并更新有效基线。
- 重复包含同一新增 ASIN 的运行不重复生成事件。
- 不完整或失败运行返回 `REJECTED_KEEP_PREVIOUS`，有效基线 ID 与 ASIN 集合保持不变。
- `PRODUCT_MATERIAL` 只能查看，不能执行监控运行；`ADMIN`、`SELECTION` 可执行。
- 监控事件确认幂等；候选记录可追溯 `sourceStore`、`sourceRunId` 和 `sourceEventId`。
- 所有响应继续执行 `SYNTHETIC` fail-closed 校验。
