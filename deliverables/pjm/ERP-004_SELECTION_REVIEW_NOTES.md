# ERP-004 候选详情与评审记录批次

## 目标

在 ERP-003 的候选来源链路基础上补齐候选详情与评审协作，使选品人员能够进入单个候选、查看完整资料，并追加不可覆盖的评审记录。

本批次继续使用 `SYNTHETIC` 内存数据，不代表生产持久化、真实用户审计或正式业务验收。

## 范围

1. 提供单个候选详情查询接口。
2. 候选详情返回现有评估资料、状态、来源链路和评审记录。
3. `ADMIN`、`SELECTION` 可追加评审记录；`PRODUCT_MATERIAL` 只读。
4. 评审记录包含内容、操作人、角色与时间，只追加、不覆盖。
5. 候选池提供详情入口，候选详情路由从占位页替换为真实页面。
6. 对不存在候选、空内容、越权写入提供稳定错误响应。

## 不在范围

- 附件上传、对象存储和病毒扫描。
- 批量导出、打印和外部分享。
- 真实 IAM 身份、数据库持久化及审计日志替代。

## 验收标准

- 候选详情可按 ID 查询，不存在时返回 404。
- 新增评审记录后立即出现在详情中，并保留操作者、角色和时间。
- 已有记录不会因追加操作被修改或删除。
- 空白记录返回 400；产品/辅料角色写入返回 403。
- 候选池可进入详情页，详情页支持返回候选池。
- Backend、Frontend、lint、typecheck、production build 和动态 HTTP 验收全部通过。
