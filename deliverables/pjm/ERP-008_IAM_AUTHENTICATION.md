# ERP-008 IAM 认证与权限闭环

## 目标

在正式非 `mock` 运行模式下实现内部账号密码登录、强制首次改密、失败锁定、账号管理、会话撤销和动作级权限控制，并保留本地合成演示模式。

## 实施范围

- 新增 IAM 用户、会话和安全事件数据库迁移。
- 使用 BCrypt 保存密码，数据库只保存随机 Bearer token 的 SHA-256 摘要。
- 支持登录、当前用户、退出、改密和管理员账号管理接口。
- 支持账号启停、解锁、角色变更、密码重置及相关会话撤销。
- 前端支持正式密码登录、强制改密、用户管理和 capability 路由/按钮控制。
- 权限集合严格使用 ERP-006 批准的 19 个 capability 和三角色映射。

## 安全边界

- 不提供公开注册、SSO、多租户、组织树和复杂数据权限。
- 不保存默认管理员密码；空库引导账号只能由受保护运行环境注入。
- `mock` profile 继续使用合成身份，不创建真实账号。
- 前端可见性只改善体验，正式 `/api/v1` 接口由后端认证与 capability 校验负责安全控制。

## 集成修复

- 将 Codex 初版的旧导入权限编码替换为 ERP-006 批准的六个通用导入 capability，移除未批准的分类导入及审计导出权限。
- 保留 ERP-007 的显式 `mysql` / `mock` / `test` 数据源 profile，未在默认配置中恢复隐式 H2。
- IAM 自动化测试固定使用 `test` profile；导入入口文案同步为当前五类导入。
