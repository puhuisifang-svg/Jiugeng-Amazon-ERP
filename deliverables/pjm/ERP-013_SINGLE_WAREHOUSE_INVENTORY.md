## 交付范围

- 固定 `MAIN` 辅料仓、正式 MySQL/H2 库存余额和追加式不可变流水。
- 正式余额、流水查询、入库、出库、盘盈、盘亏、冲销及安全库存 API。
- 余额更新与流水写入处于同一事务；默认禁止负库存。
- `requestId` 全局幂等：同载荷返回原结果，异载荷返回 409。
- 固定仓数据库行锁串行化命令，保证并发余额一致性。
- 冲销必须引用同一辅料的原始非冲销流水，且同一流水最多冲销一次。
- `OPENING` 仅通过公开稳定的 `InventoryOpeningService` 提供给 ERP-017；普通手工 API 和页面不开放。
- 安全库存阈值和低库存提示；`inventory.read/write` 权限和库存操作审计。
- 正式前端余额及流水页面；mock 模式保持原合成库存行为并明确不可冲销。

## 业务与架构约束

- 本版本只有固定单仓，不提供多仓配置 UI。
- 库存模块只通过辅料表稳定标识校验启用状态，不依赖其他模块内部 Java 类型。
- 流水没有更新和删除 API；纠错只允许生成 `REVERSAL`。
- 固定仓全局锁优先保证 MVP 正确性；多仓或高吞吐场景应在后续改为分仓/分料锁策略。
