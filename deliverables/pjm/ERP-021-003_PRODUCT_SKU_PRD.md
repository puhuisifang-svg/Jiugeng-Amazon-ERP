## 1. 目标与边界

简化产品基础信息，以 SKU 为单位集中展示图片、包装信息、供应商和辅料，让产品人员在一个详情页完成资料与用料维护。产品经理需重点确认状态含义、供应商联系方式可见范围、历史动态属性退出方式，以及与导入和首页产品引用的兼容策略。

用户明确提出的字段增删、统一名称、克单位、三态下拉、多供应商、关联辅料作为需求基础。以下必填条件、权限、上传限制及迁移策略已评审通过并冻结。

本期包含产品/SKU 新增、编辑、详情和列表同步调整；共享供应商档案及弹窗；SKU 图片；现有 SKU—辅料关联的统一入口；相应导入模板、数据迁移、权限与审计。

本期不包含采购下单、供应商报价/结算、生产与成品库存、微信消息发送、1688 自动采集、供应商门户和多层 BOM。关联辅料只维护用料关系，不自动扣减库存。

## 2. 现状与关键设计

当前 Product 包含中英文名称、品牌、内部类目；SKU 包含条码、材质、规格、重量单位和动态属性。产品已有 DRAFT/ACTIVE/DISABLED，SKU 只有 ACTIVE/DISABLED。动态属性当前参与同产品下变体组合唯一校验。

系统已实现 SKU—辅料关系，保存标准用量、单位、损耗率及备注；辅料主档有图片与规格，库存来自单仓余额。现有产品、SKU、辅料数据结构没有供应商关联。

设计原则：

- “关联辅料”复用已有关系，替换动态属性的页面位置；不把属性名称/值直接转换成辅料。
- SKU 编码继续全局唯一；允许多个 SKU 使用完全相同的辅料组合。
- 供应商独立建档，SKU 与辅料分别通过多对多关系引用；同一供应商只维护一份联系方式。
- SKU 自身供应商与辅料供应商分别展示，不自动互相继承。
- 老字段从日常维护界面退出，迁移核验完成前不物理销毁历史值。
- 数据库迁移固定使用 V16；发布必须同时验证现网 V15→V16 与空库 V1→V16。

## 3. 页面与操作流程

沿用现有产品管理导航，功能入口与正在调整的导航布局兼容，不固定左侧或顶部位置。

| 页面/区域 | 展示与操作 |
| --- | --- |
| 产品列表 | 产品编号、产品名称、状态、SKU 数量、更新时间；按编号/名称搜索、状态筛选；新建、详情、编辑 |
| 产品详情 | 基础信息、SKU、关联辅料、变更记录；辅料页签作为汇总视图，复用 SKU 内同一数据源 |
| SKU 编辑区 | SKU 编码、名称、图片、尺寸、包装重量、状态、关联供应商、关联辅料 |
| 供应商管理 | 产品管理下独立入口；名称/电话查询、启停、编辑、被引用情况；与弹窗共用档案 |
| 供应商选择弹窗 | 搜索已有档案、多选、设为主供应商、查看/维护详情、新建档案 |
| 辅料选择弹窗 | 编号/名称搜索，多选启用辅料，带出图片、规格、单位、库存与供应商摘要 |

典型流程：填写产品编号和名称 → 添加 SKU 与图片 → 关联供应商 → 选择辅料并填写用量 → 保存为待定或启用。

保存前 SKU 和关联关系均为草稿；取消整个产品编辑不新增关系。弹窗中“保存供应商档案”是明确的独立保存，成功后提示“供应商档案已保存，关联将在产品保存后生效”；取消产品编辑不删除该共享档案。

产品/SKU、供应商引用和辅料关系的正式保存作为一个整体：校验失败时不得只保存其中一部分，失败后保留输入。多人同时编辑时提示冲突，禁止静默覆盖。修改共享供应商前显示其被引用数量，说明修改会同步影响所有引用。

## 4. 产品基础信息

| 字段 | 需求与推荐校验 |
| --- | --- |
| 产品编号 | 保留，必填，沿用当前编码规则与大小写不敏感唯一约束；保存后默认不可直接改号 |
| 产品名称 | 合并中文名称、英文名称为一个字段；必填，去除首尾空格，1–128 字符，可中英文混合 |
| 产品类型 | 保留现有字段和规则，本次不新增强制分类 |
| 产品描述 | 保留现有字段和规则 |
| 状态 | 固定按“启用、待定、停用”排列；新建默认待定 |
| 品牌、内部类目 | 从表单、常规列表及详情退出，不再要求录入 |

状态与编码：推荐沿用产品 ACTIVE（启用）、DRAFT（待定）、DISABLED（停用）的存储值，减少历史兼容成本。

## 5. SKU 信息

| 字段 | 需求与推荐校验 |
| --- | --- |
| SKU 编码 | 保留、必填、全局唯一，沿用现有编码规则；不得因取消动态属性而失去唯一标识 |
| SKU 名称 | 保留；推荐必填，1–128 字符，可描述颜色、尺寸等区分信息 |
| 产品图片 | 新增，每个 SKU 首版一张主图；可上传、预览、替换、移除；未提供时显示占位图 |
| 产品尺寸、包装尺寸 | 保留现有字段与校验，不纳入本次删减 |
| 包装重量（克） | 只显示一个数值输入，单位固定显示“克”；正数，最多 3 位小数，上限推荐 999999999.999；允许空值，不以 0 代表未知 |
| 状态 | 启用、待定、停用；新建默认待定；SKU 新增 DRAFT 存储值 |
| 关联供应商 | 可关联 0–多个供应商，去重；可选一个主供应商，主供应商不必填 |
| 关联辅料 | 可关联 0–多个辅料，保留标准用量、单位、损耗率、备注及关系启停 |
| 商品条码、材质、内部规格、重量单位 | 从日常表单与展示退出；重量单位不再是可编辑字段 |
| 动态属性 | 取消新增/编辑入口，以关联辅料区域替代；历史属性只读保留 |

图片、供应商、辅料和包装重量首版不作为启用的强制条件，避免不使用辅料或供应商尚未补齐的 SKU 无法维护；若业务要求资料完整后才能启用，由产品经理另行确认必填门槛。

## 6. 状态行为

- 待定可保存未完成的选填信息，可继续编辑，不能被新的发货记录或其他正式业务选择。
- 启用必须满足编号、名称及所有已填字段/关系的有效性校验。
- 停用保留历史引用，不能新增正式业务引用；允许有权限人员编辑资料或恢复为待定/启用。
- 产品不是启用状态时，其 SKU 无论自身状态为何，均不可供新的正式业务选择。
- 产品状态变化不批量覆盖 SKU 自身状态；产品恢复启用后仍尊重各 SKU 原状态。
- 待定产品可预配置 SKU，但提示“产品启用后，启用 SKU 才可用于业务”。
- 已有发货历史和辅料关系不因停用而删除；未完成业务继续显示原引用及停用提示。
- 无物理删除产品或 SKU 的入口；状态变化记录前后值和操作者。

## 7. 供应商档案与关联

### 7.1 档案字段

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 供应商名称 | 是 | 1–128 字符；可为公司或个人名称 |
| 联系人 | 否 | 0–64 字符 |
| 电话 | 否 | 文本保存，保留 +、前导零、分机；最长 32 字符；不限定中国手机号 |
| 1688 链接 | 否 | HTTPS 链接，主机为 1688.com 或其子域；允许店铺/商品链接，不自动抓取 |
| 微信好友二维码 | 否 | 单张图片；点击放大；上传者确认属于供应商联系方式 |
| 备注 | 否 | 最长 500 字符 |
| 状态 | 是 | 启用/停用；新建默认启用 |

至少提供电话、1688 链接、二维码中的一项。名称与电话/链接重复时给出非阻断提示并推荐已有档案；不单凭同名强制合并不同供应商。业务使用内部 ID 关联，不按名称串联。编辑时移除最后一种联系方式必须拒绝。

### 7.2 关联规则

- 一个 SKU 可对应多个供应商，同一供应商在同一 SKU 下不能重复关联。
- 一个辅料可对应多个供应商；辅料主档补充相同的关联弹窗，作为本需求的必要配套。
- SKU/辅料关联均可保存“该物料采购链接”和关系备注；采购链接遵循相同的 1688 校验规则。具体商品链接优先保存在关系上，避免改动共享档案影响其他 SKU。
- 供应商摘要显示名称、主供应商标记；有联系方式权限时可展开电话、链接及二维码。
- 取消关联仅解除关系，不删除供应商。供应商停用后不能新增关联，已有关系继续显示并标记停用。
- 同一关系最多一个主供应商；取消主供应商后允许暂时没有主供应商，不自动随机选择。
- 供应商档案不提供物理删除；停用不影响历史审计和历史记录。

## 8. 关联辅料

关联单位仍为 SKU。每行展示辅料图片、编号、名称、规格、单位、当前库存、辅料供应商摘要，以及标准用量、损耗率、备注和关系状态。

- 从启用辅料主档选择，选中后读取主档信息，不允许在关系行中覆盖辅料名称/规格。
- 同一 SKU 与同一辅料仅一条关系；已有停用关系可重新启用，不重复创建。
- 标准用量必须大于 0，单位与辅料单位一致，数量精度与损耗率边界沿用现有 ERP-012 契约。
- 保留“应用到全部 SKU”：确认目标范围，预览跳过项；按现有关系去重，不静默覆盖各 SKU 的独立用量。
- 库存显示固定仓的当前现存量与单位，并显示最近刷新时间；打开弹窗/保存关系后刷新，提供手动刷新入口。
- 有权限但库存尚未初始化时标记“未初始化”；读取失败显示“暂不可用”；无权限显示“无查看权限”。不得把上述情况显示成 0。
- 库存不因页面展示或保存关联而变化；本期不计算采购缺口、占用量或可生产数量。
- 详情汇总页签与 SKU 编辑区复用同一关系；从任一入口修改后，另一入口刷新可见。
- 辅料供应商来自辅料档案；没有关联时显示“未关联供应商”，不使用 SKU 供应商填补。

## 9. 权限与审计建议

| 操作/数据 | 管理员 | 产品/辅料人员 | 选品人员 |
| --- | --- | --- | --- |
| 产品/SKU 与关联辅料基础资料 | 管理 | 维护 | 查看 |
| 产品/SKU/辅料图片 | 查看及维护 | 查看及维护 | 查看 |
| 辅料库存 | 查看 | 查看 | 不可见，维持现有边界 |
| 供应商档案、电话、二维码和采购链接 | 管理 | 维护 | 不可见 |

沿用 products.read/write、materials.read/write、inventory.read；辅料关系写权限沿用并核实现有关系权限契约。新增 suppliers.read、suppliers.write，首版仅授予管理员、产品/辅料人员；供应商列表、详情、链接和二维码资源均执行同一权限检查。选品人员看到供应商列时显示“无查看权限”，接口也不能返回相关联系方式。

新增供应商权限需同步活跃范围契约和角色测试，不将历史 19 项能力集合当成永久不可扩展限制。供应商修改、引用增删、图片变更、状态变化、辅料用量修改记录审计。电话仅保留脱敏摘要，二维码只记资源 ID，避免通过审计绕过联系方式访问限制。

## 10. 图片与交互质量

- SKU 主图和供应商二维码使用受控文件资源，支持 JPG/PNG/WebP，单图最多 5 MB；拒绝 SVG、伪装类型和无法解码图片。
- SKU 列表显示缩略图，二维码预览保持清晰比例，支持关闭和键盘操作；空图、失败图均有占位。
- 上传成功而业务未保存的资源作为临时文件，按保留策略清理；替换资源须检查其他引用后再清理，不立即删除共享文件。
- 产品图片权限随 products.read，二维码权限随 suppliers.read；未授权原图请求也必须被拒绝。
- 列表/选择弹窗支持分页、搜索、加载、空结果和错误重试；保留现有 P95 ≤ 2 秒目标，避免逐行重复查询库存和供应商。
- 弹窗关闭前检测未保存修改；保存期间禁止重复提交；失败保留输入，冲突要求重新加载确认。

## 11. 历史数据与导入兼容

### 11.1 名称与字段退出

产品名称优先取非空中文名称；中文为空则取英文名称；两者均为空则列入迁移异常，不用编号冒充名称。原英文名称和其他退出字段保留在迁移备份/历史只读记录中，列出数量及抽样核对结果。

品牌、内部类目、SKU 条码、材质、内部规格不再接受新版表单录入；旧值在迁移窗口内保留。所有产品名称消费者（搜索、详情、首页发货选择、导入预览等）同步切换；历史发货名称快照不追溯改写。

### 11.2 重量与状态

- 新接口/模板重量统一按克输入输出，固定精度，禁止随客户端传入单位而改变解释。
- 已知 g 原值保留，kg × 1000，lb × 453.59237，oz × 28.349523125，结果四舍五入至 3 位小数；实际旧数据单位先盘点。
- 单位缺失、未知单位、非正数或转换溢出的记录输出异常清单，人工确认后处理，不能静默按克解释。
- 产品 DRAFT 展示为待定；现有 ACTIVE/DISABLED 原样映射。已有 SKU 状态不重置，新 SKU 才默认待定。

### 11.3 动态属性与唯一性

保留历史属性只读快照，不自动推导成辅料，也不伪造 SKU 名称。新建/编辑不再要求属性组合；退出组合唯一校验及相应数据库限制。SKU 编码唯一规则保留。评审验收必须覆盖“两个不同 SKU、无动态属性、相同辅料组合可保存”。历史条码及其他已退出字段不得继续阻止新版新增。

### 11.4 导入与对外契约

产品、SKU 模板升级为明确版本：产品使用产品名称，移除品牌/内部类目；SKU 移除条码/材质/规格/可选重量单位/动态属性工作表，增加待定状态，重量列标注克。辅料与关系导入保留既有语义，不能因界面重组而失效。

新图片及供应商关系首版由页面维护，不新增图片批量导入或供应商导入类型。PRODUCTS、VARIANTS 模板升级为 2.0，其余三类保持 1.0；旧产品/SKU 模板明确拒绝并提供新版下载及转换说明，不静默忽略旧列。升级前已有待提交批次应在窗口内完成或取消重传；V16 后旧版未完成批次禁止提交并返回稳定错误码。已完成结果及历史文件继续可下载。若要求兼容旧模板，需产品经理批准显式转换方案和额外验收范围。

实现前完成备份、异常盘点、迁移演练；迁移失败不得应用部分关系。回滚方案必须匹配新结构，不可仅回退应用包后继续写入不兼容数据库。

## 12. 验收标准

| 编号 | 可验证结果 |
| --- | --- |
| AC-01 | 产品新建/编辑/列表/详情只使用产品名称；退出字段不再要求输入；旧中英文数据按规则迁移 |
| AC-02 | 产品和 SKU 下拉均为启用、待定、停用；新建默认待定；父产品停用后新业务不可选其 SKU，历史引用完整 |
| AC-03 | SKU 图片上传、预览、替换、移除正常；伪装文件/超限图片被拒绝；库存只读角色也不能读取供应商二维码 |

| AC-08 | 不同 SKU 无动态属性可保存，同辅料组合可保存，重复 SKU 编码仍拒绝；历史属性保持可查 |
| AC-09 | 无权限角色不能通过接口、文件地址、审计读取联系方式；不能修改产品/关系/供应商；授权修改均留痕 |
| AC-10 | 新模板与接口、页面一致，旧模板提示明确；升级批次处理和历史下载通过验证；首页产品引用无回归 |
| AC-11 | 保存失败不产生半成品关系，多人冲突不静默覆盖；临时图片清理不删除被引用资源 |
| AC-12 | MySQL 迁移、重启持久化、备份恢复、后端全门禁、前端 quality、受影响导入契约及浏览器关键流程通过 |

## 13. 产品经理决策清单

| 决策 | 推荐结论 |
| --- | --- |
| 动态属性退出后如何区分 SKU | SKU 编码唯一，名称描述规格；历史属性只读，不转为辅料 |
| 待定是否可用于发货等新业务 | 不可；父产品与 SKU 均启用才可选择 |
| 启用是否强制有图片/供应商/辅料 | 首版不强制；已填数据必须有效 |
| SKU 图片数量 | 首版一张主图，后续有实需再支持图库 |
| 供应商电话、二维码、采购链接是否对选品人员开放 | 首版不开放；维持库存原权限边界 |
| 名称合并与重量迁移 | 中文优先、英文兜底；保留原值；重量转克，异常人工核对 |
| 是否接受新版导入模板及旧批次切换窗口 | 接受明确版本切换；供应商/图片暂不做导入 |

以上推荐结论全部批准。补充冻结口径：产品名称应用校验 1–128 字符；退出字段只保留于数据库和历史只读视图，不进入新版写入 DTO，也不得继续触发新版唯一冲突；每个 SKU、每个辅料主体各自最多一个主供应商；产品/SKU、供应商引用、辅料关系和图片绑定必须由单个服务端事务提交。
