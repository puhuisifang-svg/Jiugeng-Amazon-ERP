## 2 目标与用户场景

产品人员能够直接找到某个 SKU，查看图片、包装资料、供应商和辅料，并在同一工作区完成修改。管理员能够定位重码、缺失资料与停用原因，检查修改记录。只读人员能够查询授权资料，不能通过列表、详情或导出获取受限供应商信息。

主要场景：

1. 输入 SKU 或名称找到商品，直接修改包装重量及尺寸，不必先逐个打开产品。
2. 新建一个产品并添加多个 SKU，公共资料可明确应用到选中 SKU。
3. 为已有产品增加相似 SKU，通过复制减少重复录入，但重新填写编码。
4. 按状态、资料缺失和供应商筛选，批量补齐资料或调整状态。
5. 从 SKU 查看辅料用量与当前库存，再返回列表时保留筛选和位置。

建议验收目标：精确 SKU 查询到编辑入口不超过 2 次点击（不计输入）；单 SKU 常规编辑不要求展开其他 SKU；批量操作必须可预览影响范围；无权限数据不进入接口响应、页面或导出。

## 4 术语与信息架构

| 对象 | 定义与约束 |
| --- | --- |
| 产品/SPU | 同款产品的组织单位，保存产品编码、名称、类型、描述、状态；一个产品可含多个 SKU |
| 商品/SKU | 可维护包装、图片、供应商和用料的具体单品；必须归属一个产品；编码全局唯一 |
| 产品类型 | 沿用当前描述字段，不解释为库存计算类型，不自动赋予组合或加工语义 |
| 供应商 | 独立共享档案；SKU 供应商与辅料供应商分别维护 |
| 辅料关系 | SKU 对辅料的用量、损耗率及关系状态，不是成品组合关系 |
| 业务可用 | 产品与 SKU 同时启用；不能只看 SKU 状态 |

沿用当前“产品管理”导航。进入后提供“SKU 商品列表”“产品/SPU 列表”两个视图，默认前者。供应商、辅料继续使用已有导航与档案，可从详情进入对应关联选择弹窗。

“产品/SPU 列表”仍显示没有 SKU 的产品，防止切换默认视图后主档不可查。SKU 视图每行一个 SKU，产品名称和编码作为归属信息。已有产品详情地址继续有效；详情中的 SKU 可被直接定位，页面刷新和返回仍保持选择。

## 5 商品列表

### 5.1 布局与展示

页面自上而下为：视图切换、状态页签、查询筛选、工具栏、数据表、分页。筛选区默认收起低频条件；表头固定，标识列与操作列固定，宽表横向滚动。视觉沿用现有导航和组件风格。

| 区域 | 内容 |
| --- | --- |
| 状态页签 | 全部、启用、待定、停用；SKU 视图按 SKU 自身状态计数，产品视图按产品状态计数 |
| 搜索 | 可选 SKU 编码、SKU 名称、产品编码、产品名称；名称模糊匹配，编码支持精确/包含切换，默认精确 |
| 更多筛选 | 所属产品、父产品状态、关联供应商、有无主图、有无供应商、有无辅料、包装重量是否缺失 |
| 主工具栏 | 新增商品、导入、导出、列设置、刷新；选中数据后显示批量编辑和批量状态操作 |
| SKU 默认列 | 勾选、图片、SKU 编码与名称、所属产品、SKU 状态、业务可用性、包装重量、主供应商、辅料数量、更新时间、操作 |
| 可选列 | 产品尺寸、包装尺寸、产品类型、供应商数量、父产品状态 |
| 行操作 | 查看、编辑、复制；更多中启用、设为待定、停用；按权限和当前状态展示 |

产品视图保留产品编码、名称、类型、状态、SKU 数量、更新时间；支持查看、编辑和新增 SKU。不在产品行重复展示所有 SKU 的供应商及重量，避免含义不清。

### 5.2 查询和选择规则

- 多个筛选条件按“且”组合；可见筛选标签可单独移除，一键重置只重置查询条件。
- 状态数量基于当前其他筛选条件计算，忽略状态页签自身；数量查询失败显示“—”，不冒充 0。
- 默认按更新时间倒序、内部 ID 稳定兜底；支持更新时间和编码排序。分页 20/50/100，默认 20；筛选变化回第 1 页。
- 查询、分页与排序由服务端完成，不依赖一次性加载全部产品及所有 SKU。
- 首期仅允许勾选当前页，表头全选表示“本页全选”；换页、切换视图或修改筛选清除选中项，并提示原因。
- 列设置支持显示/隐藏、拖动排序、恢复默认；标识与操作列不可隐藏。按当前账号保存在当前浏览器，退出后不串用其他账号设置。
- 打开详情再返回保留搜索、筛选、页码和滚动位置；结果因修改不再满足条件时，刷新后从结果中移除并提示。
- 无供应商权限时不提供供应商筛选或列设置，详情仍可显示“无查看权限”；不可借筛选匹配结果推断联系方式。

### 5.3 空态与失败

首次无资料显示新增入口；搜索无结果显示清空筛选入口；加载失败显示重试，不显示为“暂无商品”。无图片显示占位，图片加载失败不阻塞整行。父产品停用或待定时，在业务可用性列明确说明原因。

## 6 新增与编辑

使用宽侧栏或大弹窗，顶部固定标题与当前 SKU，底部固定“取消”“保存”。内容按“基础资料、图片与包装、供应商、关联辅料”分区；宽度不足时改为全屏编辑。多 SKU 新建使用左侧 SKU 清单切换右侧资料，错误数量标在对应 SKU 上。

### 6.1 新增商品

1. 选择“归属已有产品”或“同时新建产品”。已有产品可搜索编码与名称；默认仅展示启用和待定产品。
2. 选择停用产品需主动开启“包含停用产品”，页面提示新 SKU 暂不可用于业务，不自动恢复父产品。
3. 新建产品填写编码、名称及状态，默认待定；新增 SKU 至少一条，填写 SKU 编码和名称，默认待定。
4. 补充图片、包装、供应商和辅料；点击保存后统一提交当前草稿中的产品、SKU 与关系。
5. 成功后刷新列表，提示新增数量并提供查看入口；失败保留输入并定位字段。

新建产品的名称只在创建第一个 SKU 时作为可编辑建议值带入，后续修改产品名称不覆盖已经输入的 SKU 名称。

### 6.2 编辑已有 SKU

从商品行直接打开该 SKU 的资料，父产品基础信息只读展示，另设“编辑产品资料”入口。编辑 SKU 不应要求重新提交或覆盖其他 SKU；若底层仍使用产品聚合保存，必须携带版本并保留未编辑字段，有冲突则阻止覆盖。

已保存的产品编码与 SKU 编码在普通编辑中只读。现有管理员改号规则继续有效，本期不新增批量改号或跨产品移动 SKU。取消、关闭或切换编辑对象时，存在未保存修改则提示保留或放弃。

### 6.3 复制 SKU

复制后默认归属原产品，SKU 编码清空、名称可编辑、状态设为待定。可复制包装资料和主图引用；供应商、辅料采用复选项，默认不复制，勾选后展示关系预览。

不复制审计、业务单据、库存、历史动态属性。停用供应商、停用辅料及已停用关系不复制，展示跳过明细；复制主图沿用安全资源引用，移除新 SKU 图片不会删除原图。保存前不创建新 SKU，取消即丢弃草稿。

## 7 字段与关系规则

| 层级 | 字段 | 本期规则 |
| --- | --- | --- |
| 产品 | 编码 | 必填，手动输入，1–64 位，字母/数字开头，仅字母、数字、短横线和下划线；去首尾空格，大小写不敏感判重 |
| 产品 | 名称 | 必填，1–128 字符，允许中英文混合 |
| 产品 | 类型、描述 | 沿用现有字段及长度限制，不增加必填要求 |
| SKU | 编码 | 与产品编码相同格式，SKU 范围全局唯一；不与 ASIN、MSKU、FNSKU 混用 |
| SKU | 名称 | 必填，1–128 字符，可用名称表达颜色、尺寸等差异 |
| 产品和 SKU | 状态 | 启用、待定、停用；新建默认待定 |
| SKU | 主图 | 一张，可预览、替换、移除；沿用受控上传 JPG/PNG/WebP，最多 5 MiB，边长最多 4096 像素且总像素不超 1600 万 |
| SKU | 产品尺寸、包装尺寸 | 沿用当前文本字段，示例“20 × 10 × 5 cm”；不自动转换为结构化长宽高或计算体积 |
| SKU | 包装重量 | 固定克，选填；填写后必须为正数，最多 3 位小数，最大 999999999.999；空不等于 0 |
| SKU | 供应商关系 | 0 至多个，去重；最多一个主供应商；采购链接和备注保存在关系上 |
| SKU | 辅料关系 | 0 至多个；同一辅料仅一条关系，保留用量、单位、损耗率、备注及关系状态 |

新增主图使用本地受控上传；已有合法图片 URL 的展示兼容保留，本期不新增远程抓图和图库能力。图片缺失、供应商未关联或无辅料不阻止启用，但可通过缺失筛选定位。

供应商选择弹窗支持搜索、多选、主供应商标记及有权限时新建共享档案。联系方式、二维码、1688 域名校验等继续遵循原 PRD。独立保存供应商时提示“档案已保存，关联将在商品保存后生效”。

辅料选择展示图片、编码、名称、规格、单位和库存；库存显示来源仓与刷新时间，不因保存关系变化。读取失败、无权限、未初始化分别展示，不用 0 替代。数量和损耗率沿用已有契约，单位不在关系中任意转换。

## 8 批量操作

首期跨 SKU 批量维护仅开放状态、产品尺寸、包装尺寸、包装重量；最多处理本页 100 条。供应商及辅料的批量应用仅在同一产品编辑草稿中提供，避免一次操作影响不相关产品。

每个可编辑字段必须显式勾选，未勾选表示保持原值。清空选填值必须选择“清空此字段”；空输入不自动清空。名称、编码和所属产品不提供批量覆盖。

批量提交前展示选中数量、字段、原值/新值摘要和不可处理原因；状态操作同时提示父产品状态，不自动修改父产品。首期采用整批校验、整批提交，任一记录无权限、无效或版本过期则整批失败，不出现用户未预期的部分成功。失败明细可定位到 SKU；重试须刷新预览，重复点击不得重复创建关系或审计事件。

同产品草稿中的“应用到选中 SKU”：默认只填空值；覆盖已有值需明确选择并展示差异。辅料按辅料 ID 去重，已存在关系默认保留原用量，停用关系提示后决定是否恢复。供应商按 ID 去重；主供应商冲突需要明确选择，不随机替换。批量应用只改变草稿，保存后生效。

## 9 详情与历史

SKU 详情展示图片、编码、名称、所属产品、状态和业务可用原因，提供“基础与包装、供应商、关联辅料、变更记录”页签。供应商和辅料均读取同一份已保存关系，避免详情、表单、产品汇总各存一份。

产品详情继续显示基础资料和 SKU 清单，辅料汇总标明所属 SKU；从汇总编辑进入对应 SKU，不建立独立的产品级用料。历史动态属性保持只读。

审计记录新增、修改、复制来源、状态改变、图片绑定与关系变化，以及批量操作标识。展示操作者、时间和可读字段差异；联系方式不进入普通产品审计明文。无物理删除入口，历史发货及其他已保存业务引用不因停用丢失。

## 10 导入与导出

导入入口复用现有批次流程：下载模板、上传、预校验、错误反馈、确认提交及结果查看。PRODUCTS 与 VARIANTS 继续为 2.0，关联辅料等既有模板语义不变。不能把赛狐文件直接当作九更模板，也不通过导入恢复已退出字段。首期不新增供应商关系导入、图片导入或任意字段覆盖式导入更新。

新增商品列表 XLSX 导出，区分“当前勾选记录”和“当前筛选全部记录”，导出前显示范围、预计数量及字段；没有勾选时前者不可用。默认按当前可见业务列导出，包含编码、名称、状态及必要单位，不导出操作列、二维码、图片二进制或受控文件地址。

首期导出上限 10000 条，超过时要求缩小筛选，不能静默截断。供应商仅导出有权限用户可见的名称与主供应商标记，不导出电话、二维码及采购链接。请求和文件下载都检查权限，文件设过期时间；文本以文本单元格保存，不能将编码或名称当作公式执行。导出记录范围、数量、操作者及时间；导出的列表报表不作为回导模板。

## 11 权限与一致性

| 操作 | 管理员 | 产品/辅料人员 | 选品只读人员 |
| --- | --- | --- | --- |
| 查看产品与 SKU 基础资料、图片 | 允许 | 允许 | 允许 |
| 新增、编辑、复制、状态及批量维护 | 允许 | 允许 | 禁止 |
| 导入 | 沿用已有授权 | 沿用已有授权 | 禁止写入 |
| 基础资料导出 | 允许 | 允许 | 允许，仅基础资料 |
| 供应商档案与关联资料 | 允许 | 允许 | 禁止 |
| 辅料库存 | 允许 | 允许 | 禁止 |

以上角色沿用现有 capability 映射；接口不以按钮是否隐藏作为权限保障。拥有产品写权限但没有供应商写权限时，编辑其他字段必须保留原供应商关系，不因响应中不可见而清空。

单次新增/编辑的 SKU、图片绑定、供应商引用与辅料关系必须原子保存。共享供应商独立保存例外按第 7 节提示。使用版本冲突提示保护多人编辑，冲突后保留当前输入供比对，不静默覆盖。

状态变化不级联覆盖 SKU 自身状态。待定、停用对象不能用于新的正式业务选择；恢复父产品后仍按各 SKU 自身状态判断。批量停用前明确受影响范围，历史引用保持不变。

## 12 兼容与验收

本期保留产品、SKU、供应商、辅料和图片的既有 ID，不重建主档、不改写历史发货名称快照、不重新运行旧字段退出迁移。保存视图配置和新增审计如需数据库迁移，开发设计阶段使用届时最新迁移编号，不复用已执行的 V16。

| 编号 | 验收场景与预期 |
| --- | --- |
| AC01 | 一个产品有 3 个 SKU 时，SKU 列表显示 3 行，产品视图仍为 1 行；无 SKU 产品可在产品视图找到 |
| AC02 | 精确 SKU 查询、名称模糊查询、组合筛选、状态计数和分页一致；返回列表保留上下文 |
| AC03 | 选中后换页或筛选会清除选择；无任何操作默认覆盖未选中记录 |
| AC04 | 新建产品及多个 SKU 原子保存；重复编码、缺名称或无效重量时不产生半成品资料 |
| AC05 | 编辑一个 SKU 不覆盖其他 SKU；并发修改返回可理解冲突，用户输入保留 |
| AC06 | 复制时新编码为空、状态待定；不复制库存/历史，停用关联有跳过提示，取消不产生记录 |
| AC07 | 批量未选字段保持不变，清空需显式选择；任一对象冲突时整批不落库，结果可定位 |
| AC08 | 父产品停用、SKU 启用时明确显示不可用于业务；恢复父产品不改变 SKU 状态 |
| AC09 | 图片上传、预览、替换和移除正常；图片越权被拒绝，复制图片后的移除不损坏原商品 |
| AC10 | SKU 与辅料供应商独立；无供应商权限的查询、筛选、导出及审计均不泄露相关资料 |
| AC11 | 两处辅料入口内容一致，用量有效；无权限/未初始化/失败均不显示为 0，关系保存不改变库存 |
| AC12 | 既有 2.0 模板及导入结果可用；导出范围、排序、字段和权限正确，超限明确提示 |
| AC13 | 列配置不跨账号串用；键盘可完成搜索、打开/关闭编辑、提交；未保存退出有提醒 |
| AC14 | 历史详情链接、首页发货引用、旧图片展示、历史属性只读和审计均无回归 |

性能建议口径：在明确配置的本机验收环境中，以 10000 条合成 SKU、每页 50 条验证查询与首屏数据请求 P95 不超过 2 秒；测试报告记录环境、数据量及采样次数。模拟数据有明确标识，性能目标不等于已取得测量结果。

用户确认后，实施时按受影响范围执行后端 `./mvnw clean verify`、前端 `pnpm quality`；修改导入契约则补充对应 npm/Python 门禁；变更数据库则验证迁移与持久化。浏览器验证搜索、新建、单 SKU 编辑、复制、批量操作、权限和导出，并执行 `git diff --check`。当前为文档阶段，未执行这些开发验收。
