## 4 赛狐详情和批量操作的实际结构

### 4.1 详情

详情为比编辑弹窗更窄的居中窗口。顶部左侧图片，右侧品名、商品编码、SKU；中部是可横向切换的页签；下方双列只读资料；底部关闭、编辑。

详情页签为基础信息、物流信息、采购信息、采购历史、质检信息、规格信息、关联辅料、图片管理、税务信息、自定义字段、操作日志。操作日志有日期区间和四列表格。编辑入口进入编辑普通商品，编码类信息保持受限。

### 4.2 批量编辑

实际勾选两条记录后，“编辑”打开批量编辑弹窗。内容不是 SKU 逐行编辑表，而是按基础、物流、采购、质检、规格、头程、自定义字段分组的字段表单。每个字段前有复选框，未选时输入禁用；部分字段有覆盖/追加选项。顶部提示勾选后未填写将更新为空值；底部取消和确认。

### 4.3 导入及更多

导入下拉已看到 SKU 标签、单个商品、组合商品、加工商品、多属性商品、更新多属性商品、更新商品、关联供应商、关联辅料、1688 配对、店小秘商品入口。

## 6 九更列表详细需求

### 6.1 筛选布局

第一行依次放类型分段、状态、所属产品、有无图片、有无供应商、有无辅料、更新时间区间。供应商字段及相关筛选仅对有权限人员展示。第二行放搜索字段、关键词、精确/模糊、搜索、更多筛选及重置；筛选面板底部提供收起/展开。

首期搜索字段：SKU 编码、SKU 名称、产品编码、产品名称；供应商搜索对有权限者可用。精确搜索默认用于编码；名称默认模糊。编码去首尾空格、大小写不敏感。双击输入框或点击旁边“批量输入”打开多行输入框，首期仅用于 SKU 编码精确搜索；每行一个，去空行与重复，最多 100 个，显示有效数量。超过上限阻止执行并保留输入。搜索集合与其他条件按“且”组合。

高级筛选增加父产品状态和包装重量是否缺失。时间区间按用户界面显示时区解释，起止日均包含；结束早于开始须提示。搜索、筛选、排序和分页由服务端执行，不能仅筛当前页。

### 6.2 表格与操作

默认列：选择框、主图、SKU 编码、SKU 名称、所属产品、SKU 状态、业务可用性、包装规格 cm、包装重量 g、主供应商、关联辅料数、更新时间、操作。可选列增加产品规格、产品类型、供应商数量、父产品状态。不存在平台配对数据时不展示虚构“已配对”。

左工具栏：添加商品下拉、编辑、导入下拉、更多下拉、停用；右工具栏：自定义列、刷新、导出（图标带文字提示）。未选择时编辑和停用禁用。单行编辑也使用批量字段表单以保持工具栏一致；完整资料编辑通过行内省略号或详情的编辑按钮进入。

行内固定显示详情和省略号，省略号包括编辑、复制、启用/待定/停用；权限与状态决定可用项。点击 SKU 或详情打开当前 SKU 详情，保留列表背景和滚动位置。原产品详情链接继续可用。

表格默认更新时间倒序，以内部 ID 稳定排序；允许编码和更新时间排序。页大小 20/50/100，默认 20。左下显示已选数，右下显示总数、页码、页大小和跳页。仅支持本页选择，换页/筛选/视图切换清除选择并反馈。空结果、加载失败、首次无数据使用不同提示。

### 6.3 列设置

弹窗左侧约占 3/4，按基础资料、规格、关联资料分组显示复选字段；右侧约占 1/4，显示已选字段和拖动手柄。搜索只过滤候选，不取消已选。SKU 标识和操作列固定保留；无权限字段不进入候选项。

设置在点击保存并应用后生效，取消不变。恢复默认先改变弹窗草稿，仍需应用。当前配置按账号隔离保存在本浏览器；这是九更首期持久化范围，不声称与赛狐模板保存机制一致。后续若支持多模板，再增加模板下拉和另存按钮。

## 7 九更新增和编辑详细需求

### 7.1 窗口规范

采用居中大弹窗，宽度建议为视口 94%，最大 1440 CSS px；最大高度 90vh。顶部标题和右上关闭、中部内容滚动、底部右侧取消/保存。详情弹窗建议宽度 80%、最大 1100 CSS px。以上尺寸是九更设计建议，不是对赛狐像素的测量。

桌面主体采用双列标签对齐布局，备注、图片和关系表跨两列；窄屏在不足 900 CSS px 时改为单列，宽表自身滚动。页签过长时横向滚动，当前项始终可见。主色、密度和分隔延续现有赛狐风格导航，不使用赛狐品牌标识。

### 7.2 创建流程

“添加商品”下拉首期提供“添加单个 SKU”“为产品批量添加 SKU”。前者打开单品弹窗，后者先选择或新建产品，再填写 SKU 编码/名称清单，逐项维护详细资料。批量添加为九更扩展，不能标为赛狐已实查的多属性生成器。

单品弹窗顶部保持 SKU 名称、SKU 编码和主图，名称显示字符计数。基础页签首行增加“所属产品”，选择现有产品或展开新建产品编码、名称；不能自动把 SKU 编码作为产品编码。已有产品选中后其名称只读，修改产品本身需独立入口。

SKU 名称和产品名称上限沿用 128 字符；SKU/产品编码沿用 1–64 位及现有字符集，手工填写、大小写不敏感判重。这与赛狐页面显示的长度不同，应在 UI 上使用九更实际限制。

产品、SKU 默认待定。启用要求必填字段完整、已填数据有效，不强制图片/供应商/辅料。产品和 SKU 同时启用才允许新正式业务引用；父产品状态变化不覆盖子 SKU 自身状态。

### 7.3 五个编辑页签

| 页签 | 九更字段及操作 |
| --- | --- |
| 基础信息 | 所属产品、SKU 状态；产品类型/描述按现有归属显示；编辑产品入口；不重复创建一份不同步的产品资料 |
| 采购信息 | 添加供应商；主供应商、名称、关系采购链接、关系备注、操作的表格；共享档案详情/新建沿用授权入口 |
| 规格信息 | 商品规格：产品长、宽、高 cm；包装规格：包装长、宽、高 cm；包装重量 g；旧规格文本展示区 |
| 关联辅料 | 选择辅料；图片、编码、名称、规格、库存、标准用量、单位、损耗率、供应商摘要、关系状态、备注和操作 |
| 图片管理 | 单图本地上传、预览、替换、移除；数量 0/1；清楚标注格式与 5 MiB 上限；同步顶部主图 |

供应商弹窗首期使用九更共享档案搜索选择方式；不照搬“解析1688”按钮。独立保存新档案需提示它已保存、关系待商品保存后生效。停用供应商不可新增关联，历史关系保留标记；一个 SKU 最多一个主供应商。

SKU 辅料关系保留现有用量、单位、损耗率契约。库存须区分无权限、未初始化和读取失败，不以 0 代替；保存关系不产生库存流水。移除仅解除关系，不删除辅料主档。同产品批量应用默认补空与去重，覆盖已有用量需预览确认。

### 7.4 规格字段和兼容

产品长宽高、包装长宽高分别可整组留空；填写一项时要求三项完整，均为正数、单位固定 cm、最多 3 位小数，建议上限 999999.999。包装重量允许空，填写后大于 0、最多 3 位小数、上限沿用 999999999.999 克。单箱规格/重量、商品净重本期不伪造或从包装重量推断。

旧文本尺寸保持原文只读展示，结构化值初始为空。只有人工确认录入的数值参与结构化展示，不猜测文本中的单位或顺序；未补齐时列表展示旧值并标记“旧规格”。编辑名称等其他字段不强制补齐旧规格。历史发货快照不追溯修改。

此处是相对既有系统的实质变化：需新增字段与迁移，而非仅调整 UI。导入兼容见第 10 节；用户若决定首期仍用文本，须同步改写本节及规格验收项后冻结。

### 7.5 保存与复制

所有页签共享一个草稿，切换不保存也不丢值。一次保存原子提交 SKU、图片绑定、供应商和辅料关系；产品同步新建时也在同一事务。保存中禁用重复提交；失败保留输入，在相应页签标错误并定位。版本冲突阻止覆盖，提供重新加载和比对提示。普通编辑中编码只读，现有管理员改号流程另行保留。

复制 SKU 是九更拟新增操作，本次未验证赛狐复制弹窗。复制后编码清空、状态待定、归属原产品；可复制规格和图片引用。供应商/辅料需勾选后复制，停用关联展示跳过清单；不复制库存、审计或业务记录。取消不落库，解除复制图引用不删除原商品图片。

## 8 九更详情与操作日志

```text
┌ SKU 商品详情                                      × ┐
│ [图片]  示例商品名称                                 │
│         SKU: DEMO-001  所属产品: DEMO-SPU             │
│         状态 / 业务可用原因                          │
│ 基础信息 采购信息 规格信息 关联辅料 图片管理 操作日志  │
│ 双列只读字段 / 对应关系表                           │
├────────────────────────────────────────────────────┤
│                                    [关闭] [编辑]    │
└────────────────────────────────────────────────────┘
```

点击编辑进入同一对象的编辑模式；完成后回到已刷新的详情，再关闭返回列表。底层不堆叠多个可同时编辑的商品弹窗。无写权限不显示编辑按钮。产品资料修改、SKU 修改及关系变化使用可追溯内部 ID。

日志沿用“时间筛选 + 操作时间、操作人、操作类型、操作内容”表格；显示本 SKU 修改、复制来源和批量操作关联。供应商联系方式不进入普通产品日志明文。采购历史、税务和物流不提供空页签；已有历史动态属性通过只读历史入口保留。

## 9 九更批量编辑

按赛狐“字段复选框 + 分组表单”模式，不设计成逐 SKU 长表。首期分为基础信息（SKU 状态）和规格信息（两组长宽高、包装重量）；编码、名称、所属产品不批量覆盖。

勾选字段后才启用输入。未勾选表示不修改；勾选但未输入时提示选择“填入值”或“清空”，不自动清空。清空仅适用于选填字段，尺寸按整组清空。顶部显示已选 SKU 数量；预览列出目标、字段、新值和冲突。保存按钮在有合法变更后可用。

每次最多本页 100 条；整批预校验与原子提交。任一无权限、字段非法或版本冲突则整批失败，明确定位 SKU 并保留草稿。失败不产生部分关系或状态修改；相同请求不得重复写审计。该事务行为是九更需求，未通过赛狐真实提交测试推断。

停用操作展示数量、历史保留说明及业务不可用影响。恢复 SKU 不自动启用父产品。无物理删除入口；这是九更对赛狐删除按钮的明确适配。

## 10 导入导出和现有接口兼容

导入按钮展开产品主档、SKU、SKU 辅料关系三类已支持入口，连接现有下载模板、上传、校验、确认提交、查看结果流程。首期不增加赛狐专有文件直接导入或供应商报价导入。

PRODUCTS 2.0 保持兼容。VARIANTS 2.0 的旧尺寸文本保留导入语义，不自动解释数值；建议新增 VARIANTS 2.1，增加产品和包装长宽高 cm 列，重量仍为克。2.1 数值尺寸与旧文本不能同时作为有效新值：填写结构化组时旧文本列应为空，否则返回字段冲突。模板版本明确识别，两版均可校验，历史批次及下载不受影响。版本细化以冻结后的机器契约为准，不能静默忽略新列或复用旧列改变单位。

导出入口区分选中记录与筛选全部；显示范围、字段和预计数量，最多 10000 条，超过则要求缩小范围。按权限导出当前可见业务字段，不包含图片原始地址、二维码、电话、受限采购链接或操作列；长宽高和重量明确单位，文本按文本单元格输出，避免被解释为公式。导出报表不是回导模板。

不自动同步 Listing、采购、库存或外部平台。旧产品详情 URL、首页 SKU 选择、辅料引用、图片访问及历史字段必须兼容。

## 11 权限及交互质量

管理员、产品/辅料人员按现有权限维护资料；选品人员只能查看授权基础信息。供应商资料、库存各按 suppliers 与 inventory 权限判断；产品编辑不能因看不到供应商关系而清空它。所有约束需服务端执行，导出与文件下载也检查权限。

键盘可遍历搜索、页签、表单和底部按钮，打开弹窗后焦点进入弹窗，关闭返回原入口。未保存退出需确认；子弹窗取消回父草稿。图片有占位及失败态；关系加载失败不展示成空列表，不允许将未知关系当作空关系覆盖。

视口 1440×900 与 1920×1080 下检查两层顶部区域、筛选面板、表格、弹窗无互相遮挡；尺寸为 CSS 像素。筛选收起后释放表格空间，分页始终易找到，横向滚动不带走操作入口。
