# ERP-029 采购管理 PRD v1.0

## 目标

在独立一级菜单“采购管理”下统一管理产品 SKU 与辅料采购，复用供应商、SKU、辅料和固定仓库存能力，并形成可审计、可重放、可恢复的采购闭环。

## 冻结边界

- 一张采购单只允许一个供应商。
- 产品采购与辅料采购禁止混单。
- 产品采购单位固定为“套”；产品收货仅累计实收数量，不创建成品库存。
- 辅料单位继承辅料主档；收货与固定仓 `INBOUND` 流水在同一数据库事务内提交。
- 首版记录单价与币种，不包含付款、税费、发票、审批、退货、质检、多仓、成本核算和外部平台自动下单。

## 页面

1. 采购看板：草稿、待收货、部分收货、已完成统计及近期采购单。
2. 采购单：查询、创建、编辑草稿、提交、取消和查看详情。
3. 收货记录：按采购单分批收货，查看收货明细和幂等请求号。
4. 采购单详情：基础信息、明细、收货记录和审计时间线。

## 状态机

`DRAFT -> SUBMITTED -> PARTIALLY_RECEIVED -> COMPLETED`

- `DRAFT` 可编辑、提交或取消。
- `SUBMITTED`、`PARTIALLY_RECEIVED` 只读，可分批收货或取消未收部分。
- `COMPLETED`、`CANCELLED` 全只读。
- 禁止超收；并发收货通过订单行锁串行化。

## 权限

- `purchases.read`
- `purchases.write`
- `purchases.receive`

`ADMIN` 与 `PRODUCT_MATERIAL` 拥有三项权限；`SELECTION` 无采购菜单，直达接口返回 403。

## 数据与事务

- Flyway V22：采购单、采购明细、收货单、收货明细。
- 订单编号唯一；明细业务对象不可重复。
- 使用 `version` 乐观锁保护草稿编辑和状态变更。
- 收货请求以 `requestId + payloadHash` 持久化幂等；相同载荷重放复用结果，异载荷返回 409。
- 辅料收货调用库存公开边界，采购收货、库存余额、不可变流水、审计和订单状态同事务提交。

## 验收标准

- 单供应商、禁止混单、单位、数量、币种和价格校验通过。
- 草稿编辑、提交、取消及状态非法转换被正确处理。
- 分批收货、完成、并发防超收、幂等重放与重启持久化通过。
- 辅料收货生成库存 `INBOUND`；产品收货不产生库存副作用。
- 三角色权限、审计脱敏、V1->V22/V21->V22 迁移、mock 隔离通过。
- 后端、前端、范围契约、导入契约及生产构建全门禁通过。
