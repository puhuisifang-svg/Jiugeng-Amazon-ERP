# ERP-031 采购单实际流程完善

用户要求：产品和辅料采购分 Tab；UI 与现有系统一致；移除采购看板和收货记录菜单。

PJM 已交接独占写锁，允许从 `5e49e9f1463304e3ee9fbc54297e0eb6255fb81e` 创建 `feature/ERP-031-purchase-order-workflow`，保留 ERP-030 与最新菜单调整。

## 实施方案

1. 统一采购单入口，旧看板/收货记录路径跳转采购单，历史记录仍保留在单据详情。
2. 产品采购与辅料采购分 Tab；增加关键词、状态、交期筛选和分页，列表显示金额、逐行收货进度、交期。
3. 按当前 Tab 建单，单供应商且不得混单；选择已关联启用项目，填写数量、单价、预计到货日期、收货信息与备注；逐行金额与整单金额预览。供应商异步切换防止旧数据覆盖。
4. 草稿编辑、确认下单、分批收货、完成/取消余量。提交时重新检查供应商和项目有效性；收货保持幂等重试，禁止超收；取消要求原因且不撤销已有收货。
5. 详情集中展示交期、采购明细、收货记录、操作历史。辅料收货仍与固定仓库存同事务；产品收货不虚构尚不存在的成品库存。
6. 增量迁移兼容旧采购单（新增交期、收货信息、取消原因可空），不删除历史数据。保持原采购权限，不添加未确认的付款、发票、多级审批、质检或退货规则。

## 验证计划

前端完整 `pnpm quality`；后端 `./mvnw clean verify`；真实 MySQL 迁移/重启/HTTP 门禁；备份恢复门禁；范围契约与 `git diff --check`。覆盖两类 Tab、旧入口重定向、只读权限、异步供应商切换、保存校验、交期保存、提交时停用校验、取消原因和已收数量保留、收货未知结果同请求重试。
