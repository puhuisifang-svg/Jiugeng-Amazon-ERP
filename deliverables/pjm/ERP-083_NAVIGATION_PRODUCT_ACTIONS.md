# ERP-083 菜单、页签与产品列表操作精简

## 任务及基线

- 用户明确要求 8 项 UI 调整：悬停菜单和宽度、页签右键关闭、添加SKU选择门槛、移除重复已选统计、移除批量修改按钮、压缩表头、移除操作列展开按钮、详情加更多操作。
- 分支：`feature/ERP-083-navigation-product-actions`。开始时干净，fetch 后基于 origin/main `36f0ef95b918c9ca0921f6a6d99aa83cb9cf4953` 创建；携入 ERP-078 至 ERP-082，保留累计本地开发。
- 授权：验证后本地提交，不推送、合并 main 或部署。

## 计划与实现

1. AdminLayout：悬停展开、180ms 移出延迟、二级菜单宽度从 860px 改为最多 460px，位置随菜单按钮并限制视口范围；保留点击/键盘及权限过滤。
2. 页签支持右键和 Shift+F10：关闭当前、关闭其他、关闭全部。关闭其他保留被右击页签，关闭全部返回首页；路由守卫阻止离开时保留页签。首页固定入口不关闭。
3. 产品工具栏“添加SKU”未勾选/加载/保存中禁用；所属产品限于已选 SKU 对应父体，单个产品默认选中。移除工具栏已选统计和批量修改按钮。
4. 表头目标 36px（浏览器实测含边框 37px），操作列宽104px；保留图片原尺寸。操作列只展示详情和更多，父体详情进入现有产品详情路由。
5. 新增 RowMoreActions 独立浮层，父体编辑/删除/添加子体与 SKU 编辑/复制/删除保留权限及原确认逻辑。去掉操作列展开子体，编码前箭头仍可展开。
6. 规范升级 UI v1.3，明确上述交互和布局要求。
