# ERP-084 二级菜单高度与布局纠正

- 分支 `fix/ERP-084-navigation-menu-height`；开始检查 ERP-083 分支工作区干净，fetch 后 origin/main 仍为 `36f0ef95b918c9ca0921f6a6d99aa83cb9cf4953`。

## 参考观察与实现

实际打开 Safari 中赛狐的商品、销售、设置菜单进行观察：左侧分组、右侧横向链接；组间虚线；商品/销售均三组，设置七组，面板随组数增高，功能更多时宽度增加而非先挤成多行。截图为双倍像素，分组约 49 CSS px、商品面板约 570 CSS px 宽；设置菜单在触发项下方居中，左侧菜单受屏幕边界限制。

1. 移除 ERP-083 的 460px 宽度上限和额外纵向留白，按内容横向展开。桌面一组最小 49px，链接 32px，整块不设置固定高度。
2. 使用实际弹层宽度居中定位并限制视口两边，窗口缩放、主导航横向滚动重新计算；窗口高度不足时内部滚动。
3. 面板间距 6px，透明鼠标通道跨越间距，保留 180ms 延迟收起与切换取消旧计时；品牌悬停收起。权限过滤、点击、键盘、外部点击和 Escape 保持有效。
4. 小屏继续左右分组，右侧自然换行，不改成上下堆叠。权限过滤后没有空分组。
5. UI 规范更新 v1.4，明确取代 ERP-083 的错误宽度规则。未改变业务功能、API 或数据。
