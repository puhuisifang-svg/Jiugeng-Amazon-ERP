# ERP-088 产品默认状态与 SKU 名称展示

## 范围与分支

- 用户要求：新增父体/子体默认启用；SKU 名称支持换行及标红；列表品名优先、编码小字灰色。
- 分支：`feature/ERP-088-sku-name-display`。
- 基线：`origin/main` 的 `36f0ef95b918c9ca0921f6a6d99aa83cb9cf4953`；按用户累计开发要求携带 ERP-078 至 ERP-087 的本地提交。开始时工作区干净。
- 本任务本地提交，不推送、不合并 main、不部署线上。提交 SHA 以本文件所在提交为准。

## 实现

- ProductForm、ProductsView：新增父体、新增/复制 SKU 默认 ACTIVE；编辑保留原状态。接口省略状态时的既有 DRAFT 行为不变。
- ProductForm：200 字纯文本多行名称、独立名称标红开关，标签页小屏横向滚动；不将 HTML 或颜色写入名称。
- ProductsView：首个业务列固定品名 / SKU编码，名称在上，编码 12px 灰色在下；兼容旧列偏好并移除重复品名列。保留原编码排序、勾选、展开、详情、图片和固定操作列。
- ProductDetailView、SkuDetailDialog：保留名称换行与标红；两个编辑入口都传递标红设置。
- 后端 ProductTypes / ProductRepository / ProductController / ProductNameStyleService：返回及保存 nameHighlighted。沿用聚合写权限、乐观锁与同一事务，未传字段保留旧值，显式 false 取消。标红变更追加父体历史记录，并提供中文操作标签。
- V40 数据库迁移：新增布尔字段，历史记录默认 false。
- UI_STANDARD 同步名称层级与默认值规范。
