# ERP-096 全局 UI 一致性巡检修复

2026-10-26，用户要求检查其他页面所有功能的 UI 并统一修复。PJM 批准独占写入，累计基线 `6ce8b28906d8a195d58081b88e9a1fa2253ec561`（保留 ERP-095），分支 `fix/ERP-096-global-ui-consistency`。

## 计划

1. 逐一盘点路由与可达页面、共用组件，按筛选、列表、详情、表单/弹窗、提示与小屏分类。
2. 修共享布局、控件与溢出问题；特殊页面显式接入，避免覆盖产品编辑/成本等已有独立布局。
3. 回归权限、筛选与编辑保留行为；桌面 1280×800、800×600、360×800 使用合成数据验证。
4. 全量前端门禁、差异检查、规范与验收记录、本地提交和 PJM 交接。无后端/API/业务数据修改，不推送、合并、部署或重启。

## 已发现问题

- 订单/发票、附件和导入结果等页面存在未应用系统样式的按钮；发票导航使用禁用按钮作为选中态。
- 桌面筛选全局 width:0 对 flex 无明确宽度项有压缩风险；筛选重置视觉不统一。
- 宽表操作列并非全部固定；部分表单/卡片、长 URL 和工具栏在窄屏可把页面撑宽。
- 部分编辑弹窗操作区无底部固定规则；已有特殊 flex 弹窗应保留，不以全局重写破坏。
- 图片基础样式仍有 cover 裁切，多个页面没有覆盖为 contain。
