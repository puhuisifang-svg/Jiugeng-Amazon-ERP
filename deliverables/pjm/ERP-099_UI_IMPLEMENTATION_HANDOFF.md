样式集中于 `monitoringWorkbench.css`，复用共享密度变量及表格/分页组件。例外：添加店铺参考赛狐使用紧凑 32px 选择项（地址区仍为多行输入）；不改变其他编辑器。公开观测没有的数据显示“—”；首次发现不冒充亚马逊上架日期。

## 实现范围

- 前端：ProductMonitoringView、WatchStoresView、WatchStoreDetail，以及 useCollectionStatus；对应组件测试。
- 后端：V49 为自动店铺商品增加 image_url/price/rating，读取并保留缺失字段历史值；CollectionService 在目标设置变化后取消旧版本排队任务，显式更新立即排入新版本。
- 自动采集沿用 ERP-098 Amazon 美国站公开页面适配器。页面搜索非全量库存，不据此自动判定下架。
- 保留原入口 `http://127.0.0.1:5173`，原 8080 后端、原 MySQL 数据。实现阶段未重启持久服务。
- 本任务不声称实现赛狐所有分析能力：多站点、对比分析、销量/排名和平台未提供的数据不在本次范围。不复制赛狐账户数据。
