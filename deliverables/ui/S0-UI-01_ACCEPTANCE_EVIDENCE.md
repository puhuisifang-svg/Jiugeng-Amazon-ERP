## 3. 权限负向用例

| 编号 | 场景 | 预期 UI | 预期服务端要求 |
| --- | --- | --- | --- |
| PERM-01 | 选品人员访问 `/inventory` | 403；无库存数据 | 接口返回 403 |
| PERM-02 | 产品/辅料人员访问 `/system/users` | 403；菜单无入口 | 接口返回 403 |
| PERM-03 | 产品/辅料人员尝试编辑候选 | 写按钮不渲染 | 写接口返回 403 |
| PERM-04 | 选品人员尝试编辑 Product/Listing/辅料 | 写按钮不渲染 | 写接口返回 403 |
| PERM-05 | 普通用户查他人审计 | 操作人固定为本人 | 查询被数据范围约束/拒绝 |
| PERM-06 | 任一角色请求密钥值 | UI 无密钥值入口 | 接口不返回密钥明文 |
