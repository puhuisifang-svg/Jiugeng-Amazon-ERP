## 项目愿景

先建立简单、可信、可追溯的产品与选品工作平台，并验证 Amazon 对标店铺上新监控能力。

## 初步目标

1. 支持内部员工安全登录和基础角色权限。
2. 统一产品、SKU、辅料、标准用量关系和辅料库存台账。
3. 建立选品候选池和评估流程。
4. 验证并实现指定 Amazon 美国站公开店铺的每日上新监控。

## 初步范围

- P0：登录与三类角色、产品数据、辅料数据、单层产品—辅料关系、单仓辅料库存台账、选品候选池、店铺上新监控。
- 后置：生产、采购、成品库存、多仓/库位、财务、多层 BOM、批次/效期、质检、链接全字段监控、用户需求智能分析、多站点和移动端。

## 约束

- 内部使用，不按对外 SaaS 设计租户、计费和市场体系。
- 项目范围必须按 P0/P1/P2 管理，禁止以“照搬成熟 ERP”为无限需求来源。
- 财务、库存和销量口径必须经业务 Owner 确认并能追溯。
- 凭据和敏感数据必须按安全规范管理。

## 立项待确认

- 产品及辅料首期字段、标准用量、损耗率和库存口径
- 20～50 条真实产品/辅料样本、期初库存及导入范围
- 用于监控 Spike 的 3 个公开 Amazon 美国站店铺
- 登录用户数
- 部署环境和试点用户
