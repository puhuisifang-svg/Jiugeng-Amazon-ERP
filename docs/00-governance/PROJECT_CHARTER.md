## 项目愿景

建立统一、可信、可追溯的 Amazon 运营、供应链与财务数据平台，减少重复录入和人工对账，提升内部协作与经营决策效率。

## 初步目标

1. 统一店铺、站点、商品、订单、库存、采购、物流和财务数据。
2. 打通 Amazon 授权、数据同步、异常重试和数据对账。
3. 建立采购到 FBA、订单到利润和结算到回款的业务闭环。
4. 提供按角色授权的经营看板、报表与异常预警。

## 初步范围

- P0：权限与审计、主数据、Amazon 数据接入、订单、库存、采购、FBA、成本利润、结算回款、经营看板。
- P1：Amazon Ads、供应链深化、内部审批与消息集成、自定义报表。
- P2：AI 分析、自动化运营、多平台和移动端。

## 约束

- 内部使用，不按对外 SaaS 设计租户、计费和市场体系。
- 项目范围必须按 P0/P1/P2 管理，禁止以“照搬成熟 ERP”为无限需求来源。
- 财务、库存和销量口径必须经业务 Owner 确认并能追溯。
- 凭据和敏感数据必须按安全规范管理。
