## 1. 背景与目标

公司为工贸一体企业。首期面向 Amazon 美国站 5 个内部店铺，优先建设产品、辅料/物料与生产管理，再建设选品、对标店铺上新监控、链接监控和用户需求分析。详细边界见 [首期范围与实施规划](PHASE1_SCOPE_PLAN.md)。

## 2. 用户与场景

- 管理层
- 产品经理/产品开发
- 采购/物料专员
- 仓库
- PMC/生产计划
- 生产人员
- 品质
- 选品/市场分析
- 系统管理员

## 3. 核心流程

1. 产品定义 → 产品版本 → BOM/工艺 → 生效。
2. 生产需求 → 生产计划 → 工单 → 领料/报工/质检 → 完工入库。
3. 监控对象 → 数据快照 → 变化事件 → 告警/分析 → 选品机会卡片。

异常分支与现状流程待 Sprint 0 访谈确认。

## 4. 功能需求

每项需求必须包含：需求 ID、用户故事、业务规则、前置条件、主流程、异常流程、数据权限、验收标准、优先级和关联原型。

## 5. 非功能需求

- 性能与容量
- 安全与审计
- 可用性与恢复
- 数据完整性和及时性
- 浏览器与终端兼容性
