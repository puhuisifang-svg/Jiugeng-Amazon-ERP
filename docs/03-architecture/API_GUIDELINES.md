## 基本要求

- REST API 使用一致的资源命名、分页、排序、筛选和错误格式。
- 写操作支持幂等性；关键接口必须具备审计上下文。
- 接口必须校验功能权限和数据范围，不能只依赖前端隐藏。
- API 版本、弃用和兼容策略须明确。
- OpenAPI 文档随代码维护并进入 CI 校验。
- 批量导入、导出和长任务采用异步任务模型。

## 错误响应最小字段

- `code`：稳定的机器可读错误码
- `message`：用户可读说明
- `requestId`：链路追踪 ID
- `details`：可选的字段级错误，不包含敏感信息
