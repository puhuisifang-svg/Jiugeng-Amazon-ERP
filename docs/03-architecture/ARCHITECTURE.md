## 初步架构原则

- 首期采用模块化单体，按领域保持清晰边界。
- Amazon 数据同步与用户请求解耦，使用异步任务和本地业务模型。
- 保留关键 API/报告原始数据，支持补数、重算、对账和审计。
- 财务和库存计算采用可版本化规则。
- 达到明确容量、隔离或团队协作阈值后再拆分服务。

## 初步技术栈

- 前端：Vue 3 + TypeScript
- 后端：Java 21 + Spring Boot 3
- 数据库：MySQL 8
- 缓存/协调：Redis
- 文件：S3 兼容对象存储
- 部署：Docker + CI/CD
