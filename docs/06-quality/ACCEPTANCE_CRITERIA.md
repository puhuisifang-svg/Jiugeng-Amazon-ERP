# MVP 项目验收标准

| 字段 | 内容 |
| --- | --- |
| Owner | PM / QA / PJM |
| 版本 | v1.1 |
| 状态 | Approved |
| 最后更新 | 2026-09-27 |

## 1. 功能验收

| 范围 | 验收目标 | 证据 |
| --- | --- | --- |
| 登录权限 | 三类角色正常登录；禁用、锁定、重置和退出有效；后端越权请求拦截率 100% | API 自动化、权限矩阵用例、审计截图 |
| 产品/SKU | 一个 Product 可含多个 SKU；编码与属性组合不重复；停用可追溯 | 真实样本、数据库约束测试、变更日志 |
| 辅料关系 | 每个 SKU 可独立维护辅料、用量和损耗率；批量应用后可分别调整 | 真实辅料表核对 |
| 辅料库存 | 余额与流水汇总一致率 100%；负库存拦截率 100% | 并发/幂等测试、SQL 核对、导出结果 |
| 选品 | 手工与监控来源进入同一候选池；ASIN 查重；状态、负责人和淘汰原因可追溯 | 流程测试、审计记录 |
| 上新监控 | 基线成功建立；已知新增 ASIN 在下一次成功任务后生成且不重复；失败快照不污染基线 | 连续 7 天任务报告、模拟新增测试 |
| 导入导出 | 失败逐行说明；无静默丢数；导出与页面/数据库结果一致 | 模板、导入报告、抽样核对 |

## 2. 非功能验收

| 指标 | MVP 目标 | 统计口径 |
| --- | --- | --- |
| P0 需求覆盖率 | 100% | Approved P0 Backlog 中通过测试的比例 |
| P0/P1 缺陷 | P0 = 0；P1 无未批准遗留 | 试点发布候选版本缺陷清单 |
| 普通列表性能 | P95 ≤ 2 秒 | 试点数据量下服务端响应，不含外部采集 |
| 1,000 行导入 | ≤ 5 分钟 | 从确认提交至结果文件生成 |
| 关键操作审计覆盖率 | 100% | PRD 指定关键写操作中生成审计的比例 |
| 库存一致率 | 100% | 余额与有效流水重算一致的辅料数/总辅料数 |
| 监控任务成功率 | 连续 7 天 ≥ 95% | 已批准数据源的计划任务，排除人工暂停 |
| 监控误报率 | 人工复核 < 5% | 误报新品事件/已复核新品事件 |
| 浏览器兼容 | 最新 Chrome、Edge 核心流程通过 | QA 兼容性测试记录 |

## 3. 试点退出条件

1. 20～50 条真实脱敏产品/SKU、辅料关系和期初库存完成导入与抽样核对。
2. 三类角色分别完成一次端到端任务并签署试用反馈。
3. 一个批准的样本店铺完成 7 天连续监控；若 Spike 判定只能人工导入，则按批准的降级范围验收，不虚构自动监控能力。
4. 数据库备份与恢复至少演练一次，结果可追溯。
5. QA 提供测试报告，PJM 核验交付物，老板确认后才视为 MVP 验收。

## 4. 暂不采用的旧指标

订单重复率、财务差异、生产、采购等指标不属于当前精简 MVP，不得作为本期验收或开发范围。
