## 测试范围

- 单元测试：成本、库存、金额、状态机和权限规则
- 集成测试：Amazon 适配器、数据库、缓存、任务和对象存储
- 契约测试：Amazon API/报告字段和内部 API
- 数据对账：订单、库存、交易、结算和利润
- 端到端测试：采购到入库、FBA 发货、销售到回款
- 安全测试：越权、导出、审计、敏感数据和凭据
- 性能/恢复测试：批量同步、报表、重试、备份恢复

## 发布准入

- P0 用例通过
- 阻断/严重缺陷为 0
- 数据对账达到批准阈值
- 权限和审计验证通过
- 部署、监控、备份和回滚/修复方案可用
- QA 出具测试报告并由业务 Owner 完成 UAT
