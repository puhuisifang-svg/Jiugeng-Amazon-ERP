# 监控与告警

| 字段 | 内容 |
| --- | --- |

## 技术指标

- 服务可用性、错误率、P95/P99 延迟
- CPU、内存、磁盘、连接池和线程池
- 数据库慢查询、锁等待和容量
- Redis 命中率、内存和连接
- 异步任务积压、重试、失败和耗时

## 业务与数据质量指标

- 各店铺最近成功同步时间
- 订单、库存、财务报告延迟和缺失
- API 限流、授权过期和字段解析失败
- 库存/结算/利润对账差异
- 关键预警发送和处置状态

告警必须包含环境、服务/店铺、影响、首次时间、当前值、阈值、请求/任务 ID 和处理入口，禁止包含凭据或敏感原始数据。
