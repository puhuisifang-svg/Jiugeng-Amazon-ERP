# Sprint 管理

## 推进规则

1. PJM 起草 Sprint 目标、范围、任务、依赖、风险和验收标准。
2. 向老板汇报并根据意见修订。
3. 老板确认后，PJM 才向成员分配任务。
4. 成员提交成果、证据和自检结果。
5. PJM 核验，QA 按当前指令执行测试。
6. PJM 汇总 Sprint 结果，由老板验收。
7. 验收通过后再进入下一 Sprint。

Sprint 不以固定日历强制推进，以实际完成度和验收结果为准。

## 目录规范

每个 Sprint 创建独立目录：

```text
SPRINT-00/
├── SPRINT_PLAN.md
├── TASK_BOARD.md
├── MEETING_NOTES.md
├── ACCEPTANCE_REPORT.md
└── RETROSPECTIVE.md
```
