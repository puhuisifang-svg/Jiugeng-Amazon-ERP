## 权威性说明

- `Approved` 文档是当前执行基线。
- 同一主题存在多个版本时，以状态为 `Approved` 且版本号最高者为准。
- 口头或聊天结论须进入决策日志或对应文档后，才视为正式项目决定。
- 旧版本不得删除，应标记为 `Superseded` 并指向新版本。
