# 九更 ERP UI 规范 v1.9

状态：ERP-080 本地实现规范；线上发布需项目经理独立验收。适用于以后所有新增及修改页面。

ERP-081 增补统一分页，仍为本地待发布状态。

ERP-082 修正分页定位：主列表分页必须固定在应用可视区域底部。

## 原则

以列表和业务内容为主，借鉴赛狐紧凑导航、横向筛选、集中操作的布局，不复制其品牌或业务功能。不得通过整体缩放、隐藏关键条件、裁切按钮、缩小产品图片来压缩界面。

## 全局尺寸

统一使用 `frontend/src/styles/main.css` 中的 `--ui-*` 变量。

| 区域 | 桌面基准 | 规则 |
| --- | --- | --- |
| 主导航 | 36px 最小高、13px 字体 | 保留原权限和键盘操作，菜单不足宽时横向滚动 |
| 最近访问页签 | 独立 30px 最小高、12px 字体 | 蓝色底栏，当前页浅色标签；横向滚动 |
| 面包屑 | 独立 26px 最小高、12px 字体 | 位于标签栏下方，至少 24px 点击目标；长路径横向滚动，不截断返回入口 |
| 页面外边距 | 8px | 桌面与小屏统一 |
| 模块间距 | 6px | 禁止无内容的大留白 |
| 搜索控件/列表工具按钮 | 32px 最小高 | 13px 左右字体，按钮文字不可裁切 |
| 搜索/操作卡片内边距 | 4px 10px | 同级操作集中，允许换行 |
| 分页 | 4px 10px 内边距 | 不占用大块独立卡片 |

以上高度是最小值，不是裁切高度。缩放、长文字或无障碍字体放大时允许自然增高。

## 搜索与操作

- 主菜单鼠标悬停展开二级菜单，也支持点击和键盘进入。ERP-084 修正此前误解：关注分组高度，不限制为 460px 窄面板。采用赛狐式“左分组标题、右功能横排”，桌面每组最小高 49px、链接高 32px、上下内边距 8px、组间虚线；面板不预留空白高度，随可见分组数量增长。分组及功能垂直居中。
- 二级菜单宽度按最长分组内容展开（桌面最小 570px），最多视口减 16px，避免人为缩窄导致增高。按主菜单中心定位并限制两侧各 8px；小屏保留左右分组结构，功能自然换行、不裁切文字；高度超过可视区域时仅面板内部滚动。
- 面板与导航间保留 6px 视觉间距及连续鼠标通道；移出延迟 180ms，移回/切换菜单取消旧计时器。点击功能、外部、Escape 或移到品牌区关闭；Escape 焦点回到触发项。窗口大小和导航横向滚动变化时重算位置。权限过滤后不保留空分组，不改变任何权限及业务入口。
- 最近访问页签支持右键及 Shift+F10 打开“关闭页签 / 关闭其他 / 关闭全部”。关闭其他保留被右击页签，关闭全部返回首页；首页作为固定入口保留。路由守卫拒绝离开时不得删除对应页签。
- 产品工具栏只保留必要入口；“添加SKU”在未勾选时禁用，归属产品从已选记录确定。统计只在底部分页栏显示，不在工具栏重复；批量修改入口移除。
- 产品表头目标高 36px（含边框约 37px），排序控件不额外撑高；图片和正文行不因压缩表头而缩小。
- 产品操作列宽度 104px，只显示“详情”和“…”；编辑、复制、删除及添加子体等次级操作置于更多菜单，继续按权限展示、按忙碌状态禁用。父子展开使用编码前的箭头，不在操作列重复放展开按钮。
- 更多菜单采用独立浮层，限制在可视范围内，不受表格 overflow 或固定分页层级裁切；点击外部、Escape、滚动/窗口变化时关闭。危险操作仍进入原确认弹窗，不可直接执行删除。

- 使用现有 `.filter-panel`、`.audit-filters`、`.dashboard-filters`、`.monitor-filters`、`.sku-filter-card`；不得自建大间距搜索卡片。
- 桌面宽于 1000px 时标签与输入控件尽量同排；窄屏恢复上下标签。标签必须可见，placeholder 不能代替可访问名称。
- 保留所有查询项和重置行为，不能为了视觉精简移除业务能力。
- 搜索区重置采用 `.filter-reset-button`：32px 紧凑无边框文字按钮，紧随筛选条件；保留 hover、键盘焦点及加载中禁用反馈，不做高强调主按钮。ERP-085 首先应用于产品管理。
- 搜索栏保持 sticky；小屏限制其最大高度并允许内部滚动，保证列表仍可访问。
- 工具栏使用 `.material-toolbar`、`.page-actions` 或 `.monitor-toolbar`，按钮可换行；主操作突出，次操作使用系统次级样式，危险操作仍需明确确认。
- 状态成功反馈使用 toast；阻断性错误可保留内联信息。不得静默隐藏错误来省空间。

## 多选筛选控件

- 筛选栏的复选下拉统一复用 `frontend/src/components/FilterMultiSelect.vue`，参考赛狐“全部站点”的复选交互；禁止使用原生多行 select 或另写页面专属控件。
- 使用 `v-model` 绑定编码数组，`options` 传入 `{ value, label }[]`，`label` 提供可访问的字段名称，`disabled` 控制禁用。显示业务中文，提交原始编码；未知编码保留可辨识提示，不合并成同一个选项。
- 触发框高32px、字体13px；未选显示“全部＋字段名”，单选显示名称，多选显示“已选 N 项”。长名称省略，不能撑宽筛选栏。
- 弹层宽300px、最多视口宽减16px；内部搜索框高32px、选项区最高220px并独立滚动。采用浏览器 popover 顶层，避免被表格、筛选卡及弹窗裁切；滚动或窗口变化时重算位置。
- 弹层顺序为：搜索框、全选/清空、复选列表、已选数量/完成。搜索支持中文名称和原始编码；无结果显示“没有匹配选项”。
- “全选”文字固定使用蓝色 `#2864c5`，与“清空”“完成”保持一致；不得再显示“全选当前结果”。有搜索条件时仍只操作当前匹配项，并保留其他已选项；无搜索时操作全部选项。部分选中显示半选状态，无匹配项时禁用全选。
- “清空”清除全部已选项；“完成”、点击外部或 Escape 关闭弹层，保留已勾选项；完成/Escape 后焦点回到触发框。多选不会自动执行页面查询，点击页面“查询”后应用条件。
- 同一字段内多值为 OR，不同字段间为 AND；服务端分页的列表必须由接口执行筛选，不得只过滤当前页。选项接口与列表接口遵循相同权限范围，失败需提示并提供重试。
- 验收覆盖搜索、全选/半选、清空、键盘关闭、中文显示、组合筛选、分页和权限隔离；不得让全局标签/输入框样式把弹层搜索框压缩为零宽。

## 日期与时间控件

- 所有日期、日期时间和计划时刻输入复用 `frontend/src/components/DatePicker.vue`，禁止新增独立原生日历外观。
- 范围筛选合并为“开始日期 ～ 结束日期”输入框；桌面双月日历、快捷范围（今天、昨天、最近7天、最近30天、本月、上月、最近6个月、今年），选完两端提交；可一键清空。
- 日期时间范围保留时分秒并点击确定；快捷范围结束于当天23:59:59。沿用各页面原时区转换及查询触发规则，不能把日期字段静默改为UTC。
- 单日期复用日历；纯时刻不附带日期且保留分钟精度。编辑区40px、筛选区32px。保留required、min/max、禁用、手动输入与键盘焦点。
- 浮层使用浏览器popover顶层，避免被表格、筛选卡或dialog裁切。Escape/取消丢弃未提交选择；移动端单月翻月、时间范围两行显示，浮层限制在视口内并可滚动。

- 组件绑定约定：单值使用 `v-model`；范围额外传 `range` 和 `v-model:end`。`type` 为 `date`、`datetime-local` 或 `time`，通过 `startLabel` / `endLabel` 明确两端含义；`change` 只通知页面，由页面决定何时查询或保存。
- 显示统一为紧凑边框输入区，范围两端共用外框，以“～”分隔，保留日历图标、空值提示、清空和焦点状态；不得恢复两块独立日期卡片。弹层使用统一日历及选中区间样式，非当月日期弱化、不可选日期禁用。
- 确定、取消和快捷选择关闭弹层后，焦点返回日历触发按钮，不聚焦原生日期输入框；关闭操作须阻止外层 label 的默认激活，避免弹层关闭后再次打开。
- 普通日期选择完成即更新绑定值；日期时间手选需要“确定”，快捷范围直接应用；关闭未确定的浮层不覆盖已提交值。手动输入仍沿用原表单校验。
- 验收覆盖单日期、日期范围、日期时间范围、纯时刻、快捷范围、清空、取消、起止边界和禁用状态；桌面双月与手机单月均须实际检查，不以单元测试替代视觉验收。

## 列表、表单与弹窗

- ERP-088 / ERP-089：产品列表首个业务列固定为“品名 / SKU编码”（勾选列保留），名称在上、编码在下，编码使用 12px 灰色文字，不再重复显示单独品名列。SKU 名称支持纯文本换行；ERP-089 将整段标红开关替换为选中文字设置黑色/红色、加粗/常规，下方实时预览。无选区时提示先选中文字，不隐式应用整段；提供全选名称。名称仍是可检索纯文本，分段格式独立存储，仅允许颜色和字重白名单，不接受 HTML。产品列表、SKU 详情及父体 SKU 概览复用 ProductName。历史普通名称保持黑色，整段标红保持红色。新增父体和新增/复制子体默认启用，编辑不得覆盖原状态。
- 列表沿用 TableViewport 单一滚动容器及固定表头；不得通过外层 overflow 裁切操作列。
- 保持产品图片已有尺寸及 contain 展示，保留点击预览；不得因紧凑化改回裁图。
- 编辑表单仍采用现有 40px 控件及清晰分组，不将列表密度强制套用到全部输入场景。
- 产品编辑遵循 ERP-079 左父体、右 SKU 布局，900px 以下上下排列；弹窗底部操作可见。
- 父体详情面包屑为“商品 / 产品管理 / 产品详情”，产品管理必须可点击返回；面包屑下不重复放返回、刷新工具栏。ERP-087 修正：保留“基础信息”和“变更记录”两个页签，SKU 概览在基础信息内，不恢复采购、辅料或文件等父体页签。变更记录操作类型采用中文语义名称，未知类型显示“其他操作”并在 title 保留原始代码。点击概览 SKU 复用列表 SkuDetailDialog，关闭后仍留在父体页面。
- 列表及父体详情的编辑必须共用 ProductEditDialog（外层弹窗）和 ProductForm（表单），禁止在详情页直接铺表单。沿用左右布局、内部滚动及固定可见操作区；子体编辑定位到所选 SKU。保存中禁止关闭，误点阴影不清空内容，失败在弹窗显示并保留输入；编辑须保留父体图片及 SKU 报关资料。窄屏卡片设置 `min-width: 0`，宽表只在表格容器内滚动。
- 触屏场景需检查实际点击可用性；不允许小于 24px 的点击目标。保留键盘焦点、标签及跳转到内容入口。

## 分页规范（ERP-081）

- 所有业务主列表分页必须复用 `frontend/src/components/ListPagination.vue`，不得再独立实现上一页/下一页工具条。
- **主列表分页固定在应用可视区域底部**，不是跟在最后一行数据下面，也不是仅在长列表滚动到底后才出现。空列表、短列表、长列表均遵循同一底部位置。
- AdminLayout 提供独立 `#workspace-pagination` 底部网格区域；ListPagination 自动挂载到当前应用壳层的该区域。内容滚动与分页分离，底部区域真实参与布局，高度随窄屏换行变化，禁止用覆盖数据的 fixed 悬浮条代替。
- 表格高度按扣除底部区域后的内容边界计算；最后一行数据和横向滚动条可访问。弹窗分页留在弹窗内部，不占用主页面底部；路由切换/组件卸载时清除旧分页。
- 桌面布局：左侧总数/已选统计，右侧依次为上一页、数字页码、下一页、每页条数、前往页码。保留系统橙色当前页，避免把全部分页按钮做成高强调主按钮。
- 数字页码展示首页、末页、当前页附近页码，中间以省略号收起；页数大时不能铺满整行。
- 通常默认 20 条，提供 10/20/50/100 条；接口若固定容量须传 `sizes` 明确限制，不显示虚假选项。监控历史当前接口固定 20 条。
- 改变每页条数先更新 size，再回第一页并查询一次；保留查询条件，不得查询后仍显示旧条数。
- 组件 page 为从 1 开始的展示页码；服务端从 0 开始的接口必须在页面边界转换，避免漏页、重复页。
- 支持点击数字页码、输入正整数后 Enter 或失焦跳页；越界值限制到合法范围，空值、负数、小数或非数字恢复当前页，不发无效查询。
- 零条记录显示共 0 条、页码 1，禁用前后翻页与跳页；加载中禁用分页操作。首页/末页禁用对应方向按钮。
- 产品父子结构按父体分页，统计必须标注父体/子体，不能将父体总数写成 SKU 总数；原有选中统计通过 summary 插槽保留。
- 控件高 32px、数字按钮最小宽 32px，外层内边距 4px 10px。分页在表格横向滚动容器外，不跟随宽表滚出屏幕；小屏统计与操作自动换行，禁止裁切或整体缩放。
- 页码按钮具备可读 aria-label，当前页标记 aria-current="page"，条数和跳页输入具备可访问名称。
- 弹窗内用于检索选项的客户/SKU 选择器保留其上下页按钮和明确对象名称，不视为业务主列表；无分页的全量/概览页面不增加虚假分页。
- 回归必须覆盖页码边界、空列表、加载锁定、数字跳页、非法跳页、改条数回第一页和服务端参数转换；禁止按按钮 DOM 序号断言下一页。

## 验收与维护

- 2026-10-30 用户授权全系统紧凑化：`workspaceDensity.css` 仅覆盖查询与工具区，使用 `#main-content` 限定作用域统一旧模块差异，不得扩展为全站控件或图片缩放。按用户反馈修正为菜单、页签、面包屑三层独立行，保持返回、关闭、右键菜单及键盘操作。641px 以上搜索标签与输入横排；手机普通网格筛选可同行，搜索区最多占 30dvh，超出后内部滚动。中等宽度产品搜索将重置放在两行条件旁，避免独占第三行。编辑表单维持 40px 控件；列表图片及正文行不缩小。分页最小高 41px，仍参与底部独立布局。

- ERP-097：未保存关闭确认不得以表单顶部的文字加裸按钮展示。复用 `UnsavedChangesDialog`，使用独立顶层确认窗、清晰标题和影响说明；“继续填写”为主操作并默认聚焦，“放弃并关闭”为红字次操作。确认窗阴影不关闭，Escape 返回继续填写，关闭后恢复原焦点；原表单保持挂载以保留输入。外箱标须区分“尚未生成”和“尚未保存”，明确历史 PDF 不受影响。已具有独立确认卡的页面保留既有交互。
- ERP-096：共享防溢出、按钮兜底和弹窗操作区规则集中在 `styles/uiConsistency.css`，低优先级默认样式不得覆盖专用编辑器。横向 flex 筛选使用 `.ui-filter-row`，必须给标签项明确宽度，禁止 `width:0` 与无宽度父项组合导致输入框塌缩。宽表需要固定操作列时显式使用 `.ui-action-table`，不得自动把所有表格最后一列当成操作列。台账切换使用 `.ui-section-tabs` 与可读选中状态，不用 disabled 表示当前页签。
- ERP-096：业务确认和原因填写统一使用 `confirmAction` / `promptReason` 与全局 `UiConfirmationHost`，禁止新增 `window.confirm` / `window.prompt`。原业务文案、权限与后续请求保持不变；取消、Escape、路由变化和宿主卸载不能执行确认操作，重复触发不能覆盖待确认内容。真正关闭/刷新浏览器的 `beforeunload` 安全提示仍由浏览器负责。
- ERP-096：编辑表单误点阴影不得清空；取消/关闭仍保留原有未保存保护。操作区固定于弹窗底部，native dialog 与内部卡片只能有一个纵向滚动主体；复杂宽表保留自身横向滚动。上传控件必须约束宽度，`.sr-only` 上传 input 不得被通用 100% 宽度规则撑开。取消/关闭使用次级按钮，不与保存争夺主强调。图片基础样式统一 contain，矩形图片不裁切。
